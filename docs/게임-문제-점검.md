## 잘된 게임과 비교한 큰 그림 (의견)

185. **Hades**: 방마다 보상을 골라 판이 매번 달라진다. 이 게임의 탑은 보상 0 · 문 하나라 판마다 같다 → 「탑 밖 준비 → 탑 시험」 구조라면, 적어도 층 특성(어둠 · 광풍 · 피의 달 · 무리)을 매 층 고르게 하는 정도의 선택이 필요하다.
186. **Enter the Gungeon / Soul Knight**: 층마다 방 모양 · 함정 · 상자가 다르다. 여기는 빈 방 + 몬스터 물결 셋뿐이다.
187. **Stardew Valley**: 생활 콘텐츠가 이야기 · 관계와 묶인다. 여기 농사 · 낚시 · 요리는 「탑 안 회복」 하나로만 이어진다.
188. **Diablo · Path of Exile**: 각인(빌드) 효과가 화면에서 바로 보인다(불 각인 → 칼에 불). 여기는 대부분 숫자 · 깃발이라 새겨도 전투 화면이 바뀌지 않는다.
189. **Vampire Survivors**: 숫자 인플레이션을 쓰지만 화면은 단순하다. 여기는 숫자도 크고 글자 정보도 많아, 둘 다 읽기 어렵다.
190. **Children of Morta / Moonlighter**: 캐릭터 동작 칸이 공격마다 8~12칸이다. 여기는 몸 4칸 + 무기 조각 회전이다.
191. **Dead Cells**: 레벨이 없고, 영구 성장은 「새 무기 · 새 길」이다. 여기는 레벨 · 스탯 · 각인 · 장비 · 강화 · 수련 · 정령 · 숙련이 다 숫자를 올린다 → 한두 개로 줄이는 편이 낫다.
