# 각인의 탑 — 문제 해결 방안 (2026-11-05)

`docs/게임-문제-점검.md`의 문제 191개를 어떻게 풀지 정리했다. 번호는 점검 문서 번호다.
**새 방향: 탑을 올라 새 콘텐츠를 해방한다.** 이 방향 하나로 구조 문제 상당수(B · C · D)가 함께 풀린다.

---

## 0. 새 방향 — 탑이 섬을 연다

### 원칙
1. **처음에는 작게 시작한다.** 바람결 마을 · 시작 평원 · 꽃바람 들판 · 거울 호수, 그리고 탑 1~10층만 열려 있다.
2. **보상은 탑 밖에서 받는다.** 탑 안 규칙(각인 · 보상 없음, 문 하나, 10층 세이브)은 그대로 둔다. 구역의 주인(10층마다) · 수호자(5층마다)를 처음 쓰러뜨리면 **섬의 새 지역과 새 체계가 열린다.**
3. **고리가 한 바퀴씩 커진다.** 탑 N구역 돌파 → 새 지역이 열린다 → 그 지역에서 사냥하면 다음 구역에 맞는 부산물이 나온다 → 각인 → 다음 구역. 탐험 → 사냥 → 각인 → 등반 고리가 구역마다 다시 돈다.
4. **지역 레벨대를 탑 구역에 맞춘다.** 새로 열린 지역 = 다음 탑 구역의 권장 레벨대.
5. **잠긴 것도 보여 준다.** 지도에는 봉인 표시(안개 · 탑 문양)가 있고, 다가가면 "탑 20층의 주인을 쓰러뜨리면 열린다"라고 알려 준다. 무엇이 기다리는지 알아야 오르고 싶어진다.
6. **해방은 연출로 보여 준다.** 주인을 쓰러뜨리고 탑을 나오면 꼭대기 빛줄기가 그 지역으로 날아가 봉인이 깨진다(배너 + 짧은 카메라 이동). 여정(J)은 곧바로 새 지역을 가리킨다.

### 해방 표 (초안 — 확인받을 것)

| 해방 조건 | 새로 열리는 지역 (권장 Lv) | 새로 열리는 체계 |
|---|---|---|
| 처음부터 | 바람결 마을 · 시작 평원(1~5) · 꽃바람 들판(5~10) · 거울 호수(3~8) | 공명 제단(각인) · 대장간(강화) · 의뢰 게시판 · 요리(모닥불) |

- 화산 지대(바깥 45~50 → 25~30) · 서리 설원(40~45 → 35~40) · 그림자 묘지(35~40 → 40~45)는 **탑 구역과 같은 주제 · 비슷한 레벨대**로 옮긴다(50 · 51번 해결).
- 각성 지대는 51~100층 재활용(43번)과 도감 점수 상한(59번)을 함께 푼다. 새 몬스터가 생겨 도감 점수가 늘어나고, 51층 이후 10층마다 열 것이 생긴다.
- 서약은 50층으로 옮긴다(47번).
- 온라인(파티 · 결투 · 길드 · 랭킹)도 단계별로 연다. 처음 하는 사람의 화면이 가벼워진다(40번).

### 만들 것
- `data/unlocks.js` 표 하나: `{ id, need: { lord: 2 } | { guardian: 1 }, regions: [...], systems: [...], text }`. 지역 · 오브젝트 · 메뉴는 이 표만 보고 열리거나 잠긴다.
- 세계 쪽: 잠긴 지역 경계에 **봉인 벽**(지나갈 수 없는 빛의 장막 + 안내판). 잠긴 체계의 NPC · 오브젝트는 "아직"이라는 대사를 하고, 버튼은 숨긴다.
- 저장: `save.unlocks = { id: 날짜 }`. 옛 저장은 `climb.lords` · `best`를 보고 한 번에 계산해 준다(이미 오른 사람에게서 빼앗지 않게).
- 여정(J)은 해방 표로 다시 만든다: 「구역 주인 → 새 지역 가 보기 → 그 지역 몬스터 부산물로 각인 하나 → 다음 구역」(39 · 48번).
- 시험 `tools/tests/unlock.mjs`: 해방 순서 · 옛 저장 변환 · 단계마다 권장 레벨에 닿을 도감 점수가 있는지(59번).

## 2. 설계를 바꿔야 하는 것

### A. 버그 중 설계가 걸린 것
- **16 사령술사 Q가 영혼이 없으면 안 나감** → 영혼이 없어도 해골 병사 2마리를 부르고, 모아 둔 영혼은 「더 많이 · 더 세게」로만 쓴다. 다른 클래스에서도 「무엇이 있어야만 쓰는」 스킬을 찾아 같은 방식으로 바꾼다(시체 폭발 75번도 같다: 시체가 없으면 내 발밑 뼈를 터뜨린다).
- **17 회복 표기 ≠ 실제** → `heal()`의 숨은 배율(×0.35 · ×0.3 · ×0.4 · 전투 중 ×0.4)을 없애고, **각인 · 스킬 수치 자체를 낮춰** 표기 = 실제가 되게 한다. 초당 회복 상한을 남긴다면 툴팁에 "전투 중 초당 최대 3%"라고 적는다. 시험: 각인 툴팁 수치 vs 10초 실측.
- **18 탑 안 레벨 업 · 숙련** → 탑 안에서는 도감 점수 · 숙련 횟수만 쌓고, **레벨 업 · 깨달음은 탑을 나올 때 결산 화면에서** 한꺼번에 받는다. 결산 화면이 해방 · 레벨 업을 함께 보여 주는 「보상의 순간」이 된다.

### B. 처음 10분
- **26 · 27 핵심 고리를 안 가르침 · 글 벽** → 환영 창은 세 줄로 줄인다("탑의 빛이 꺼져 간다 / 몬스터를 잡아 부산물을 모으고 / 공명 제단에서 각인을 새겨 탑을 오르자"). 튜토리얼 뒤에 **첫 고리 퀘스트**를 붙인다: 평원 멧돼지 3마리 → 부산물 → 제단에서 첫 각인 → 탑 1층. 각 단계는 화살표로 안내한다.
- **30 · 32 시작 화면 알림 과다 · 목표 둘** → 튜토리얼 · 첫 고리 동안에는 여정 하나만 보이게 한다. 의뢰 게시판은 10층 해방 뒤부터 연다.
- **34 클래스 미리보기 없음** → 클래스 카드에 대표 스킬 2개를 고리 없이 움직이는 그림(GIF처럼 캔버스 반복)으로 보여 주고, "스킬 8개 중 4개를 제단에서 고른다"라고 한 줄 적는다.
- **35 종족 · 직업 이름이 섞임** → 화면 이름을 「종족」 → 「혈통」(또는 「출신」)으로 바꾸거나, 기사 · 마법사 · 암살자 종족에 진짜 종족 이름(예: 인간 기사단 → 「서약의 인간」)을 붙인다. 확인받을 것.
- **38 첫 화면부터 모든 체계가 열림** → 0장 해방 표로 해결.

### C. 게임 구조
- **39 · 48 여정 순서 · 레벨 목표** → 0장(여정을 해방 표로 다시 만든다).
- **40 체계 과다** → 0장. 그래도 겹치는 것은 묶는다: 채광 · 벌목 · 삽질 → 「채집」 하나(도구 하나), 정치 · 관리 처치 · 교역 길드 → 「왕도」 한 묶음.

  - 판 밖 선택은 키운다: 탑에 들어가기 전에 **각인 4칸 · 음식 3칸 · 물약을 고르는 준비 화면**.
