# 각인의 탑 — 본편 개편 (탑 등반 로그라이트)

> 2026-10-27. 만든 그대로를 적었다. 사용자 요청: "스팀에서 10억을 버는 게임으로. 재미 · 많은 콘텐츠 · 분명한 목표 · 무너지지 않는 밸런스 · 너무 쉽지 않게. PC 먼저."

## 0. 지금의 문제 (직접 해 보고 찾은 것)
| 문제 | 실제로 본 것 |
|---|---|
| 목표가 안 보인다 | 첫 화면이 긴 글 한 장. 그 뒤엔 넓은 섬에 던져진다. 무엇을 위해 무엇을 할지 화면에 없다. |
| 너무 쉽다 | 시작 평원 멧돼지 셋을 1.5초에 잡고 피해 0. 탑 1층도 같다. |
| 탑이 단조롭다 | 층마다 "계단 찾기 + 시간 등급"뿐. 오를수록 숫자만 커지고 결정할 것이 없다. |
| 시스템이 따로 논다 | 각인 · 탑 · 레이드 · 성지 · 생활 · 정치가 각자 다른 규칙과 화면. 서로 이어지는 고리가 약하다. |
| 화면이 엉성하다 | 스킬 이름이 서로 겹치고, 지역 이름과 「근처에서 벌어지는 일」 상자가 겹치고, 채팅 글이 창 위에 뜬다. |

## 1. 한 줄 정의
**탑을 오르며 각인을 새기고, 매번 다른 조합으로 꼭대기를 노리는 액션 로그라이트 RPG.**
섬(바깥 세계)은 준비 · 성장 · 이야기의 무대로 그대로 남는다.

## 2. 핵심 고리
1. **준비** — 마을에서 장비 · 스킬 · 탑의 축복(영구 성장)을 고른다.
2. **등반** — 층마다 싸우고 → 보상을 고르고 → 다음 문을 고른다. 5층마다 수호자, 10층마다 구역의 주인.
3. **귀환** — 쓰러져도 **별빛**은 남는다. 별빛으로 탑의 축복을 배우고 다시 오른다.
4. **목표** — 50층 꼭대기. 그 뒤엔 **서약**(난이도)을 걸고 더 높은 기록.

## 3. 층의 흐름
- 들어가면 적이 있다. **적을 모두 쓰러뜨리면** 층이 열린다 (화면 위에 「남은 적 n」).
- 가운데에 **보상**이 나타난다 (지난 층에서 고른 문의 보상).
- 보상을 받으면 **문 2개**(축복으로 3개)가 열린다. 문 위에 다음 층의 보상이 보인다. 걸어 들어가 G.

### 보상 (문에 붙는 것)
| 보상 | 내용 |
|---|---|
| 각인 | 각인 3개 중 하나를 새긴다. 이미 가진 각인이 나오면 그 각인 **연마**(+1단계, 단계마다 효과 +12%, 최대 5) |
| 연마 | 가진 각인 3개 중 하나를 +1단계 |
| 축복 | 수치 축복 3개 중 하나 (피해 +8% · 최대 체력 +12% · 공격 속도 +8% · 치명타 +6% · 재사용 -8% · 이동 +8% · 흡혈 +3% · 받는 피해 -6%) |
| 금화 | 탑 금화 (이번 등반에서만 쓰는 돈, 상인에게 쓴다) |
| 샘 | 체력 40% 회복 |
| 별빛 | 별빛 파편 (영구 성장 재료) |
| 상인 | 다음 층은 싸움 없는 상인의 방. 각인 · 축복 · 회복 · 다시 고르기를 탑 금화로 산다 |
| 시련 | 다음 층의 적이 모두 강화 개체. 보상: 희귀 이상 각인 + 별빛 |
| 제단 | 위험과 보상을 바꾸는 선택 (피의 계약 · 도박 · 저주받은 힘) |

- 각인 등급: 1 일반 · 2 고급 · 3 희귀 · 4 영웅 · 5 전설. 층이 높을수록 높은 등급이 잘 나온다.
- 이미 가진 각인과 **태그가 겹치는 각인이 더 잘 나온다** → 조합을 노릴 수 있다 ("맞물리는 조합이 이긴다").
- 등반에서 새긴 각인은 **부하를 차지하지 않는다**(탑의 힘). 탑을 나가면 사라진다.

## 4. 탑 금화 · 별빛 · 기록
- **탑 금화**: 층에서 줍고 보상으로 받는다. 상인에게 쓴다. 등반이 끝나면 남은 금화의 절반이 섬의 골드가 된다.
- **별빛 파편**: 층마다 1 · 시련 +3 · 수호자 +5 · 구역의 주인 +12. 쓰러져도 100% 남는다.
- 등반이 끝나면 **결산 화면**: 오른 층 · 새긴 각인 · 쓰러뜨린 적 · 걸린 시간 · 얻은 별빛.

## 5. 탑의 축복 (영구 성장 · 탑 문 앞의 각인사)
| 축복 | 단계 | 효과 |
|---|---|---|
| 단단한 몸 | 5 | 최대 체력 +4% |
| 날 선 의지 | 5 | 모든 피해 +3% |
| 두 번째 숨 | 1 | 쓰러지면 체력 25%로 한 번 일어난다 (별빛 150) |
| 다시 보는 눈 | 3 | 보상 다시 고르기 +1회 |
| 넓은 길 | 1 | 문이 3개 |
| 행운의 문양 | 4 | 희귀 이상 각인 확률 +5% |
| 상인의 벗 | 3 | 상인 가격 -10% |
| 출발의 각인 | 2 | 등반을 시작할 때 각인 1개를 고른다 |
| 샘물의 기억 | 3 | 층을 깰 때마다 체력 +3% |
| 금빛 손 | 3 | 탑 금화 +15% |
| 별의 인도 | 5 | 별빛 +10% |

## 6. 서약 (난이도) — 10층의 주인을 처음 쓰러뜨리면 열린다
서약을 걸수록 **별빛이 더 많이**(서약 점수마다 +10%). 기록에 서약 점수가 붙는다.
| 서약 | 단계 | 효과 |
|---|---|---|
| 강철 피부 | 3 | 적 체력 +15% |
| 날카로운 이빨 | 3 | 적 공격력 +15% |
| 메마른 샘 | 2 | 모든 회복 -25% |
| 정예의 시대 | 3 | 강화 개체 확률 +20% |
| 수호자의 분노 | 2 | 수호자 체력 +25% · 처음부터 분노 |
| 좁은 문 | 1 | 문이 하나 줄어든다 |
| 조급한 탑 | 1 | 한 층에 90초가 넘으면 초마다 피해 |
| 탐욕의 대가 | 1 | 상인 가격 +40% |

## 7. 구역과 주인
| 층 | 구역 | 5층 수호자 | 10층 주인 |
|---|---|---|---|
| 1~10 | 이끼 굴 | 가면 족장 | 이끼 군주 |
| 11~20 | 독늪 | 늪 마녀 수장 | 늪의 거인 |
| 21~30 | 화산 균열 | 방패 악귀 대장 | 균열 수호자 |
| 31~40 | 서리 회랑 | 얼음 오우거 왕 | 서리 마녀 |
| 41~50 | 그림자 묘지 | 망령 기사단장 | 각인의 왕 (최종) |
- 주인은 체력이 셋으로 나뉘고 단계마다 기술이 바뀐다 (예고 원 · 예고선 · 표식 · 둘레 폭발 · 부하).
- 구역의 주인을 쓰러뜨리면 다음 구역 첫 층부터 시작할 수 있다. 중간부터 시작하면 그만큼 **출발 각인**을 고른다.

## 8. 목표 안내 (여정)
- 화면 오른쪽 위(작은 지도 아래)에 **지금의 목표 하나**가 늘 보인다. 장소가 있으면 화면 가장자리에 **방향 화살표**.
- 여정은 차례로 이어지는 목표 목록(J). 하나를 마치면 보상과 다음 목표.
- 예: 탑 앞에 가기 → 탑 1층 → 각인 3개 → 탑의 축복 배우기 → 5층 수호자 → 레벨 5 → 장비 강화 → 내 종족 성지 → 10층의 주인 → 서약 걸기 → 20층 …

## 9. 밸런스 (정한 수치)
- 탑의 몬스터: 바깥보다 체력 3.2배 · 공격 0.85배에서 시작해 층마다 체력 ×1.068 · 공격 ×1.044, 구역이 바뀔 때 한 계단 더
  (구역 배율 체력 1 / 1.3 / 1.75 / 2.4 / 3.3 · 공격 1 / 1.18 / 1.4 / 1.68 / 2.0). 구역마다 몬스터 종류의 평균으로 나눠 맞춘다.
- 수호자 체력 ×2.1 · 주인 ×2.3 (그 층 보통 몬스터 기준의 정의값에 곱한다). 수호자 · 주인은 몸집도 1.2 / 1.4배.
- 적 수: 8 + 층 × 0.45 (시련 ×1.15). 물결 셋, 앞 물결이 2~3마리 남으면 다음 물결.
- 강화 개체 확률: 10% + 구역마다 5% (+ 서약 「정예의 시대」 단계마다 20%).
- **권장 레벨보다 낮으면** 레벨 하나마다 적 공격력 +4%(최대 +60%) · 체력 +3%(최대 +45%). 화면 오른쪽에 숫자로 보인다.
- **탑의 가호**: 탑 안에서는 누구나 최대 체력 +250 (몸이 약한 클래스도 버틸 수 있게).
- 클래스 보정은 몬스터 상대(`CLASS_BAL_PVE`)와 결투(`CLASS_BAL`, 예전 그대로)를 나눴다.
- 바깥 세계 · 던전의 보통 몬스터 체력 ×1.7 (한 대에 쓰러지지 않게).

## 9-1. 층의 특성 (4층부터 싸움터의 약 27%)
| 특성 | 내용 |
|---|---|
| 어둠의 층 | 빛이 거의 없다 · 탑 금화 +30% |
| 광풍의 층 | 적이 25% 빠르다 · 탑 금화 +50% |
| 피의 달 | 적 공격력 +15% · 처치마다 체력 2% 회복 |
| 보물의 층 | 보물 고블린 둘 · 보물 상자 |
| 무리의 층 | 적이 40% 많다 · 별빛 +2 |
- 그 밖에 싸움터에는 가끔 보물 고블린(12%) · 보물 상자(35%)가 나온다. 고블린은 도망쳐도 층은 열린다.

## 9-2. 새 각인 18개 (탑의 문양 · 제단에서도 새길 수 있다)
불티 · 동상 · 무쇠 가죽 · 빠른 손놀림 · 굶주린 칼날 · 바람 발걸음 · 거울 결계 · 저주 낙인 · 화염 연쇄 · 서리 파동 · 독 망토 · 거인의 손아귀 · 그림자 일격 · 피의 의식 · 점액의 부활 · 폭풍의 심장 · 빙하의 심장 · 역병의 군주 (모두 82개)

## 10. 화면 정리
- 처음 화면의 긴 글 → 짧은 세 줄 + 조작.
- 스킬 칸 이름이 겹치지 않게, 오른쪽 위 글 · 상자가 겹치지 않게, 창이 열리면 채팅 글을 숨긴다.
