# 탑 보스 기술 정리

> `node tools/bossdoc.mjs` 로 만든 문서 (데이터에서 자동). 보스마다 체력 100~66% · 66~33% · 33% 아래 세 단계로 기술이 바뀐다.
> ★ = 보스가 회복하는 기술 · 능력

## 1~10층 · 이끼 굴

### 5층 수호자 · 가면 족장
- **공략**: 돌격을 벽으로 유도하면 부딪혀 기절한다
- **패시브**: 광분 (15초마다 공격 속도 +10%)
- **1단계**: 연속 베기 · 뛰어들기 · 밀쳐내기 · 족장의 돌격
- **2단계 (66%)** — 「족장이 가면을 벗었다」 · 공격 ×1.3 · 빠르기 ×1.15: 뛰어들기 · 연속 베기 · 고블린을 부른다 · 회전베기 · 족장의 돌격 · 족장의 세 번 뛰기
- **3단계 (33%)** — 「족장이 피를 뒤집어썼다」 · 공격 ×1.2 · 빠르기 ×1.15 · 패시브 불꽃 몸 (가까이 있으면 초당 화상 1중첩): 족장의 돌격 · 뛰어들기 · 고블린을 부른다 · 회전베기 · 땅 내려찍기 · 족장의 세 번 뛰기

| 기술 | 하는 일 | 피하는 법 |
|---|---|---|
| 연속 베기 | 짧은 예고 뒤 세 번 벤다 (0.22초 간격) | 물러나거나 구른다 |
| 뛰어들기 | 예고 원으로 날아가 내려찍는다 | 원 밖으로 |
| 밀쳐내기 | 세게 쳐서 멀리 날린다 | 보스 정면을 피한다 |
| 족장의 돌격 | 굵은 빨간 예고선(0.8초)이 끝나면 예고선 끝(벽이면 벽 앞)까지 달린다 | 예고선 옆으로 비키거나 구른다 |
| 고블린을 부른다 | 부하 둘을 깨운다 | 부하가 붙기 전에 보스를 몰아치거나, 부하부터 정리 |
| 회전베기 | 둘레를 한 바퀴 벤다 | 원 밖으로 |
| 족장의 세 번 뛰기 | 내 자리로 세 번 연달아 뛰어내린다 | 멈추지 말고 계속 움직인다 |
| 땅 내려찍기 | 0.8초 뒤 퍼지는 충격파 | 원 밖으로 · 구르기 |

### 10층 주인 · 이끼 군주
- **공략**: 뿌리로 회복할 때 세게 때려 끊어라
- **패시브**: ★재생 (3초 동안 맞지 않으면 초당 체력 1% 회복) · 무리 (18초마다 부하 둘을 부른다)
- **1단계**: 땅 찍기 · 뛰어들기 · 장판 · ★뿌리 흡수
- **2단계 (66%)** — 「이끼가 온몸을 덮었다」 · 공격 ×1.2 · 패시브 보호막 (20초마다 최대 체력 12% 보호막): 땅 찍기 · 부하 호출 · 이끼 비 · 뛰어들기 · 부채꼴 사격 · ★뿌리 흡수 · 뿌리 가시 길
- **3단계 (33%)** — 「고목이 썩어 무너진다」 · 공격 ×1.2 · 빠르기 ×1.2 · 패시브 독 기운 (가까이 있으면 초당 독 1중첩): 포자 폭발 · 부하 호출 · 이끼 비 · 돌진 · 뿌리의 표식 · ★뿌리 흡수 · 뿌리 가시 길 · 파문

| 기술 | 하는 일 | 피하는 법 |
|---|---|---|
| 땅 찍기 | 0.8초 뒤 퍼지는 충격파 | 원 밖으로 · 구르기 |
| 뛰어들기 | 예고 원으로 날아가 내려찍는다 | 원 밖으로 |
| 장판 | 예고 원(1초)이 터진다 | 원 밖으로 |
| ★ 뿌리 흡수 | 3초 동안 버티면 체력 18% 회복 (초록빛 · 체력바에 회복될 몫이 깜빡인다) | 3초 안에 보스 최대 체력의 7%만큼 때리면 끊기고 3초 기절 (빈틈) |
| 부하 호출 | 부하 둘을 깨운다 | 부하가 붙기 전에 보스를 몰아치거나, 부하부터 정리 |
| 이끼 비 | 모든 사람 발밑과 둘레에 장판이 떨어진다 (바닥에만) | 발밑 원에서 벗어난다 |
| 부채꼴 사격 | 부채꼴로 다섯 발 | 탄 사이로 빠지거나 옆으로 크게 돈다 |
| 뿌리 가시 길 | 보스에서 나를 향해 가시가 차례로 솟는다 (벽에서 멈춘다) | 옆으로 비킨다 |
| 포자 폭발 | 1.2초 뒤 보스 둘레 반경 110이 크게 터진다 | 멀리 떨어진다 |
| 돌진 | 굵은 빨간 예고선(0.8초)이 끝나면 예고선 끝(벽이면 벽 앞)까지 달린다 | 예고선 옆으로 비키거나 구른다 |
| 뿌리의 표식 | 한 사람을 따라다니는 원이 2.2초 뒤 터진다 | 동료에게서 떨어진다 |
| 파문 | 안 → 밖으로 고리 셋이 차례로 터진다 | 이미 터진 고리 안으로 들어간다 |

## 11~20층 · 독늪

### 15층 수호자 · 늪 마녀 수장
- **공략**: 분신은 금방 부서진다 — 버티는 쪽이 진짜
- **패시브**: 저주의 표식 (12초마다 표식: 4초 동안 받는 피해 +30%)
- **1단계**: 부채꼴 사격 · 장판 · 순간이동 · 환영 분신
- **2단계 (66%)** — 「마녀가 진짜 모습을 드러냈다」 · 공격 ×1.25 · 빠르기 ×1.2: 장판 · 부하 호출 · 빙글 도는 탄 · 순간이동 · 환영 분신 · 저주의 파문 · 운석 비
- **3단계 (33%)** — 「마녀가 늪과 하나가 되었다」 · 공격 ×1.2 · 패시브 독 기운 (가까이 있으면 초당 독 1중첩): 독비 · 부하 호출 · 빙글 도는 탄 · 저주의 표식 · 순간이동 · 환영 분신 · 저주의 파문 · 운석 비

| 기술 | 하는 일 | 피하는 법 |
|---|---|---|
| 부채꼴 사격 | 부채꼴로 다섯 발 | 탄 사이로 빠지거나 옆으로 크게 돈다 |
| 장판 | 예고 원(1초)이 터진다 | 원 밖으로 |
| 순간이동 | 잠깐 사라졌다가 다른 자리에 나타난다 | 나타난 자리를 보고 다시 붙는다 |
| 환영 분신 | 분신 둘을 만들고 셋이 자리를 섞는다 | 분신은 금방 부서진다 — 버티는 쪽이 진짜 |
| 부하 호출 | 부하 둘을 깨운다 | 부하가 붙기 전에 보스를 몰아치거나, 부하부터 정리 |
| 빙글 도는 탄 | 탄이 소용돌이로 퍼진다 | 탄 사이 틈으로 |
| 저주의 파문 | 안 → 밖으로 고리 셋이 차례로 터진다 | 이미 터진 고리 안으로 들어간다 |
| 운석 비 | 내 자리에 세 번 떨어진다 | 계속 움직인다 |
| 독비 | 모든 사람 발밑과 둘레에 장판이 떨어진다 (바닥에만) | 발밑 원에서 벗어난다 |
| 저주의 표식 | 한 사람을 따라다니는 원이 2.2초 뒤 터진다 | 동료에게서 떨어진다 |

### 20층 주인 · 늪의 거인
- **공략**: 제물을 모두 쓰러뜨리면 거인이 무너진다
- **패시브**: 독 기운 (가까이 있으면 초당 독 1중첩)
- **1단계**: 장판 · 부채꼴 사격 · 뛰어들기 · 독덩이 비
- **2단계 (66%)** — 「늪이 넘쳐흐른다」 · 공격 ×1.2 · 빠르기 ×1.2: 독비 · 장판 · 부하 호출 · 갈라지는 탄 · 늪의 제물 · 독덩이 비 · 파문
- **3단계 (33%)** — 「거인이 독을 토해 낸다」 · 공격 ×1.25 · 빠르기 ×1.15 · 패시브 광분 (15초마다 공격 속도 +10%): 독 폭발 · 독비 · 부하 호출 · 늪의 표식 · 빙글 도는 탄 · 늪의 제물 · 독덩이 비 · 파문

| 기술 | 하는 일 | 피하는 법 |
|---|---|---|
| 장판 | 예고 원(1초)이 터진다 | 원 밖으로 |
| 부채꼴 사격 | 부채꼴로 다섯 발 | 탄 사이로 빠지거나 옆으로 크게 돈다 |
| 뛰어들기 | 예고 원으로 날아가 내려찍는다 | 원 밖으로 |
| 독덩이 비 | 내 자리에 세 번 떨어진다 | 계속 움직인다 |
| 독비 | 모든 사람 발밑과 둘레에 장판이 떨어진다 (바닥에만) | 발밑 원에서 벗어난다 |
| 부하 호출 | 부하 둘을 깨운다 | 부하가 붙기 전에 보스를 몰아치거나, 부하부터 정리 |
| 갈라지는 탄 | 날아가다 여러 갈래로 갈라지는 탄 | 갈라지기 전에 멀리 떨어진다 |
| 늪의 제물 | 제물 셋을 부른다. 7초 안에 다 쓰러뜨리면 보스가 무너진다(기절), 못 하면 큰 폭발 | 제물부터 쓰러뜨린다 |
| 파문 | 안 → 밖으로 고리 셋이 차례로 터진다 | 이미 터진 고리 안으로 들어간다 |
| 독 폭발 | 1.2초 뒤 보스 둘레 반경 110이 크게 터진다 | 멀리 떨어진다 |
| 늪의 표식 | 한 사람을 따라다니는 원이 2.2초 뒤 터진다 | 동료에게서 떨어진다 |
| 빙글 도는 탄 | 탄이 소용돌이로 퍼진다 | 탄 사이 틈으로 |

## 21~30층 · 화산 균열

### 25층 수호자 · 방패 악귀 대장
- **공략**: 방패가 빛나는 동안 때리면 내가 다친다
- **패시브**: 가시 갑옷 (가까이서 때리면 피해의 15%를 돌려받는다)
- **1단계**: 연속 베기 · 방패 밀치기 · 방패 돌격 · 반사 방패
- **2단계 (66%)** — 「방패가 불타오른다」 · 공격 ×1.3 · 패시브 불꽃 몸 (가까이 있으면 초당 화상 1중첩): 방패 돌격 · 불꽃 회전 · 부하 호출 · 방패 밀치기 · 반사 방패 · 악귀의 대베기
- **3단계 (33%)** — 「악귀 대장이 방패를 내던졌다」 · 공격 ×1.3 · 빠르기 ×1.25 · 패시브 광분 (15초마다 공격 속도 +10%): 방패 돌격 · 땅 찍기 · 부하 호출 · 불꽃 회전 · 장판 · 반사 방패 · 악귀의 대베기 · 쇠사슬 끌어당기기 · 세 번 뛰기

| 기술 | 하는 일 | 피하는 법 |
|---|---|---|
| 연속 베기 | 짧은 예고 뒤 세 번 벤다 (0.22초 간격) | 물러나거나 구른다 |
| 방패 밀치기 | 세게 쳐서 멀리 날린다 | 보스 정면을 피한다 |
| 방패 돌격 | 굵은 빨간 예고선(0.8초)이 끝나면 예고선 끝(벽이면 벽 앞)까지 달린다 | 예고선 옆으로 비키거나 구른다 |
| 반사 방패 | 2.6초(각성 3.2초) 동안 방패가 빛나며 맞은 피해를 되돌린다 (「때리지 마라!」) | 빛나는 동안 때리지 않는다 |
| 불꽃 회전 | 둘레를 한 바퀴 벤다 | 원 밖으로 |
| 부하 호출 | 부하 둘을 깨운다 | 부하가 붙기 전에 보스를 몰아치거나, 부하부터 정리 |
| 악귀의 대베기 | 앞쪽 거의 반원을 크게 벤다 | 보스 등 뒤로 돌아간다 |
| 땅 찍기 | 0.8초 뒤 퍼지는 충격파 | 원 밖으로 · 구르기 |
| 장판 | 예고 원(1초)이 터진다 | 원 밖으로 |
| 쇠사슬 끌어당기기 | 사슬 예고선 — 맞으면 보스 앞으로 끌려가 곧 내려찍힌다 | 예고선에서 벗어난다 |
| 세 번 뛰기 | 내 자리로 세 번 연달아 뛰어내린다 | 멈추지 말고 계속 움직인다 |

### 30층 주인 · 균열 수호자
- **공략**: 도는 광선은 같은 방향으로 돌며 피해라
- **패시브**: 보호막 (20초마다 최대 체력 12% 보호막)
- **1단계**: 부채꼴 사격 · 땅 찍기 · 장판 · 회전 균열 광선
- **2단계 (66%)** — 「균열이 넓어졌다」 · 공격 ×1.25: 균열 광선 · 불비 · 부하 호출 · 뛰어들기 · 회전 균열 광선 · 십자 균열 · 운석 비
- **3단계 (33%)** — 「균열이 수호자를 집어삼킨다」 · 공격 ×1.25 · 빠르기 ×1.15 · 패시브 저주의 표식 (12초마다 표식: 4초 동안 받는 피해 +30%): 마그마 분출 · 균열 광선 · 불비 · 부하 호출 · 표식 · 회전 균열 광선 · 십자 균열 · 운석 비 · 파문

| 기술 | 하는 일 | 피하는 법 |
|---|---|---|
| 부채꼴 사격 | 부채꼴로 다섯 발 | 탄 사이로 빠지거나 옆으로 크게 돈다 |
| 땅 찍기 | 0.8초 뒤 퍼지는 충격파 | 원 밖으로 · 구르기 |
| 장판 | 예고 원(1초)이 터진다 | 원 밖으로 |
| 회전 균열 광선 | 예고 뒤 광선이 한쪽으로 돌며 쓸고 지나간다 (벽에서 멈춘다) | 도는 방향 반대로 돌아 광선 뒤에 선다 |
| 균열 광선 | 빨간 조준선(0.9초)을 보여 준 뒤 곧은 광선. 벽에서 멈춘다 | 조준선 옆으로 비킨다 · 벽 뒤로 숨는다 |
| 불비 | 모든 사람 발밑과 둘레에 장판이 떨어진다 (바닥에만) | 발밑 원에서 벗어난다 |
| 부하 호출 | 부하 둘을 깨운다 | 부하가 붙기 전에 보스를 몰아치거나, 부하부터 정리 |
| 뛰어들기 | 예고 원으로 날아가 내려찍는다 | 원 밖으로 |
| 십자 균열 | + 모양 광선 → 비스듬한 × 모양 광선 (예고선이 먼저 보인다) | 광선 사이의 틈으로 옮겨 다닌다 |
| 운석 비 | 내 자리에 세 번 떨어진다 | 계속 움직인다 |
| 마그마 분출 | 1.2초 뒤 보스 둘레 반경 110이 크게 터진다 | 멀리 떨어진다 |
| 표식 | 한 사람을 따라다니는 원이 2.2초 뒤 터진다 | 동료에게서 떨어진다 |
| 파문 | 안 → 밖으로 고리 셋이 차례로 터진다 | 이미 터진 고리 안으로 들어간다 |

## 31~40층 · 서리 회랑

### 35층 수호자 · 얼음 오우거 왕
- **공략**: 기술을 몇 번 쓰면 숨을 고른다 (피해 2배)
- **패시브**: 냉기 (가까이 있으면 초당 냉기 1중첩)
- **1단계**: 빙판 내려찍기 · 뛰어들기 · 연속 베기 · 얼음 손아귀

- **공략**: 1단계 왕의 검술 · 2단계 8종족의 각인 · 3단계 빛의 핵이 드러날 때 몰아쳐라
- **패시브**: 보호막 (20초마다 최대 체력 12% 보호막) · 가시 갑옷 (가까이서 때리면 피해의 15%를 돌려받는다)
- **1단계**: 왕의 검술 · 왕의 대베기 · 왕의 도약 · 왕의 돌진
- **2단계 (66%)** — 「왕이 8종족의 각인을 깨운다」 · 공격 ×1.25 · 빠르기 ×1.1 · 패시브 저주의 표식 (12초마다 표식: 4초 동안 받는 피해 +30%): 각인 빌리기 · 왕의 검술 · 왕의 대베기
- **3단계 (33%)** — 「꺼져 가는 빛의 핵이 드러났다」 · 공격 ×1.3 · 빠르기 ×1.2 · 패시브 광분 (15초마다 공격 속도 +10%) · 최후의 발악 (쓰러지면 1.4초 뒤 둘레가 크게 터진다): 빛의 핵 · 각인 빌리기 · 빛의 십자 · 꺼져 가는 빛 · 마지막 빛의 파문

| 기술 | 하는 일 | 피하는 법 |
|---|---|---|
| 왕의 검술 | 짧은 예고 뒤 세 번 벤다 (0.22초 간격) | 물러나거나 구른다 |
| 왕의 대베기 | 앞쪽 거의 반원을 크게 벤다 | 보스 등 뒤로 돌아간다 |
| 왕의 도약 | 예고 원으로 날아가 내려찍는다 | 원 밖으로 |
| 왕의 돌진 | 굵은 빨간 예고선(0.8초)이 끝나면 예고선 끝(벽이면 벽 앞)까지 달린다 | 예고선 옆으로 비키거나 구른다 |
| 각인 빌리기 | 8종족의 기술을 빌려 쓴다 | 머리 위 기술 이름을 보고 그 기술에 맞게 피한다 |
| 빛의 핵 | 3.5초 동안 핵이 드러난다 (피해 2배). 끝나기 0.9초 전부터 핵이 부풀어 둘레 7칸이 터진다 | 몰아치다가 부풀기 시작하면 빠진다 |
| 빛의 십자 | + 모양 광선 → 비스듬한 × 모양 광선 (예고선이 먼저 보인다) | 광선 사이의 틈으로 옮겨 다닌다 |
| 꺼져 가는 빛 | 예고 뒤 광선이 한쪽으로 돌며 쓸고 지나간다 (벽에서 멈춘다) | 도는 방향 반대로 돌아 광선 뒤에 선다 |
| 마지막 빛의 파문 | 안 → 밖으로 고리 셋이 차례로 터진다 | 이미 터진 고리 안으로 들어간다 |
