# 각인의 탑

**섬을 탐험해 몬스터 지대를 찾고, 사냥으로 얻은 부산물로 각인을 새겨 강해진 뒤, 탑을 오르는 2D 도트 액션 RPG.**
무대는 아르케의 바람결의 섬. 핵심은 **"강한 각인보다 맞물리는 조합이 이긴다"**.

## 한눈에 보는 고리
1. **탐험** — 섬에서 몬스터 지대를 찾는다 (지역마다 권장 레벨 · 몬스터 · 곡이 다르다).
2. **사냥** — 몬스터마다 고유한 **부산물**과 계열 잔향이 떨어진다.
3. **각인** — 바람결 마을의 **공명 제단**에서 부산물로 각인을 새긴다 (Q · E · R · F 칸 = 각인의 스킬 + 패시브).
4. **수련** — 종족 성지에서 수련으로 강해지고, 의뢰를 받는다. 대장간에서 장비를 강화한다.
5. **등반** — 각인의 탑. 탑 안에는 각인 · 보상이 없다. 탑 밖에서 갖춘 그대로 오른다.
6. **생활** — 농사 · 낚시 · 요리. 요리는 탑 안에서 H로 먹으면 체력이 돌아오는 유일한 길(물약 Z 말고).
- 무엇을 할지 모르면 **여정**(J)이 다음 한 걸음과 화살표를 보여 준다.

## 탑 등반
| 구역 | 층 | 5층 수호자 | 10층 주인 | 권장 Lv |
|---|---|---|---|---|
| 이끼 굴 | 1~10 | 가면 족장 | 이끼 군주 | 1+ |
| 독늪 | 11~20 | 늪 마녀 수장 | 늪의 거인 | 10+ |
| 화산 균열 | 21~30 | 방패 악귀 대장 | 균열 수호자 | 19+ |
| 서리 회랑 | 31~40 | 얼음 오우거 왕 | 서리 마녀 | 28+ |
| 그림자 묘지 | 41~50 | 망령 기사단장 | 각인의 왕 | 37+ |
| (각성) 51~100 | | 같은 수호자 · 주인이 각성해 돌아온다 | | 44+ |

- 층마다 **몬스터만**: 물결 셋으로 몰려오고, 모두 쓰러뜨리면 문 하나가 열린다. 층을 깨면 떨어진 부산물이 모두 날아와 주워진다.
- **세이브는 10층마다**: 구역의 주인을 쓰러뜨리면 다음부터 11 · 21 · 31 …층에서 시작할 수 있다. 중간에 쓰러지거나 나가면 그 등반은 끝난다 (쓰러지면 주운 것의 60%).
- 회복: 수호자 · 주인을 쓰러뜨리면 체력 40% (`BOSS_HEAL`). 그 밖에는 음식(H) · 물약(Z).
- 탑 안에서는 누구나 최대 체력 +250 (탑의 가호).
- 권장 레벨보다 낮으면 레벨 하나마다 적 공격 +4% (최대 +40%) · 체력 +3% (최대 +30%).
- **서약**(첫 구역의 주인을 쓰러뜨리면 열림): 적 체력 · 공격 · 회복 · 정예 · 수호자 · 조급한 탑 — 기록에 서약 점수.
- 수치는 `public/js/data/climb.js` 한 곳, 층별 몬스터 체력 · 공격은 `public/js/data/curve.js` (`node tools/curve.mjs gen`).

## 조작
- PC: WASD 이동 · 마우스 조준 · 좌클릭(누르고 있기) 평타 · 우클릭 무기 기술 · Q·E·R·F 스킬(차지 스킬은 길게) · Space 구르기 · G 상호작용 · H 음식 · Z 물약 · C 캐릭터 · I 장비 · B 가방 · J 퀘스트 · M 지도 · Esc 일시정지
- 게임패드: 왼쪽 스틱 이동 · 오른쪽 스틱 조준 · RT 평타 · LT 무기 기술 · LB/RB/Y/B = Q/E/R/F · A 구르기 · X 상호작용 · Start 일시정지 · Back 캐릭터 · 창에서는 십자키 + A / B
- 모바일: 왼쪽 조이스틱 이동 · 오른쪽 조이스틱 공격 · 스킬 · 대시 · 메뉴 버튼
- 설정(Esc → 설정): 소리 · 자동 조준 · 마을 사람 때리기 · 화면 흔들림 · 피해 숫자 · 창 글자 크게 · 전체 화면

## 종족
| 종족 | 다루기 | 고유 메커니즘 |
|---|---|---|
| 기사 | 쉬움 | 맞을수록 오러가 쌓이고, 오러를 실어 강타한다. 받는 피해 -10%. |
| 오크 | 쉬움 | 때리고 맞으며 분노가 차오른다. 분노로 광전사가 되거나 최후의 일격을 날린다. |
| 엘프 | 보통 | 정령과 함께 싸운다. 정령력이 저절로 차오르고, 멀리서 맞힐수록 투사체 피해 증가(최대 +30%). |
| 용족 | 보통 | 불을 다루는 고대 혈통. 화상에 면역이고, 불타는 적에게 주는 피해 +15%. 불타는 적이 있을 때 용기가 차오른다. |
| 공룡 수인 | 보통 | 사냥할수록 본능이 끓어오른다. 본능 50 이상이면 이동·공격 속도 +10%. |
| 마법사 | 어려움 | 마력으로 주문을 시전한다. 시전 중에는 움직일 수 없고, 강한 주문일수록 오래 걸린다. 원소 반응 피해 +50%. |
| 암살자 | 어려움 | 피하고 파고들며 그림자를 모은다. 회피·치명타·대시로 그림자가 쌓이고, 적의 등 뒤를 치면 피해 +30%. |
| 언데드 | 어려움 | 영혼을 거둬 저주를 터뜨린다. 독과 출혈에 면역, 마법 피해 +12%. 일반 회복은 절반이지만 처치마다 생명력 6% 흡수. |

클래스는 종족마다 둘(16개). 시작 무기는 클래스가 정하고, 공명 제단에서 언제든 바꿀 수 있다.

## 무기와 스킬
무기 23종, 무기마다 Q 스킬(회전베기·충전 일격·돌진 찌르기·회오리·일제 사격·화살비·도끼 폭풍·마력 폭발·서리 고리·역병 웅덩이·유성). 마법 무기는 마나를 소모하고, 민첩 무기(활·단검·쌍검·카타나)는 민첩으로 피해가 오릅니다.

## 조합 시스템
| 층 | 내용 |
|---|---|
| 스탯 8종 | 근력(물공) · 마력(마공) · 민첩 · 체력 · 감각 · 정신(상태이상 저항/감소) · 물리 저항 · 마법 저항 |
| 특수 스탯 | 흡혈 · 반사 · 독성 · 화염/냉기 친화 · 관통 · 강인함 (각인·장비에만 붙음) |
| 특화 보상 | 포인트 효율 구간 ×1.0/1.3/1.7/2.2, 30/50/70/90 각성, **극한**(1위 스탯이 2위의 2배 이상이면 +20%) |
| 조건 효과 | 스탯 임계, 스탯 비교(마력 > 근력), 스탯 차이(물저·마저 차이 10 이하), 태그 수, 종족, 극한, 만능 |
| 태그 시너지 | 화염, 냉기, 독, 출혈, 흡혈, 바람, 거체, 반사, 점액, 그림자, 저주, 불사, 투사 |
| 원소 반응 | 증기 폭발(화상+냉기) · 유독 연기(중독+화상) · 혈빙(출혈+냉기) · 패혈(중독+출혈) |
| 트레이드오프 | 각인 부하 한도(20 + 정신 10마다 1)를 넘게 장착할 수 없다, 화염·냉기 4개씩 → 상쇄, 묘지기의 계약(피해 +40%, 회복 불가) |
| 저항 상성 | 해골은 물리 저항이 높고, 망령은 물리가 거의 통하지 않음. 지속 피해는 저항을 무시 |

고등급 각인은 부하가 크고 태그가 1개뿐이라, 저등급 각인 여러 개로 시너지를 쌓은 빌드가 더 강해질 수 있습니다.
숨겨진 잔향도 있습니다. 예를 들어 얼음 골렘을 **불타는 상태로** 처치하면 다른 잔향이 나옵니다.

## 코드 구조 (온라인 확장 대비)
```
public/js/
  data/     종족·스탯·각인·몬스터·장비 (순수 데이터, 서버와 공유)
  sim/      build.js 빌드 계산 · conditions.js 조건 엔진 · mapgen.js 필드 생성 · world.js 전투·탐험 (DOM 없음)
  render/   16px 도트 스프라이트 · tiles.js 맵 미리 그리기 · renderer.js 조명·안개·HUD (읽기 전용)
  ui/       마을 화면
  save.js   저장 (순수 JSON)
```
- 전투는 **고정 60틱 + 시드 난수 + 입력**만으로 진행됩니다. 서버에서 같은 코드를 돌리면 서버 권한 방식이나 리플레이 검증이 가능합니다.
- 빌드 코드(캐릭터 탭)로 빌드를 공유합니다. 나중에 고스트 PvP와 랭킹에 사용합니다.

## 근접과 원거리
- 근접 무기: 받는 피해 -20%, 공격을 맞히면 적의 공격 준비를 끊음(경직)
- 원거리 무기: 쏘는 동안 이동 속도 -35%, 40px 안쪽은 피해 -30%, 70px 밖은 +10%

## 광장 시설
공명 제단(각인 64종, 스타일 필터·배지·목표 찜) · 대장간(장비, 장착 전 수치 변화 미리보기) · 의뢰 게시판(3개 의뢰, 완료 보상) · 서고(도감) · 수련장(교관 스탯 배분, 허수아비 DPS 측정) · 북쪽 관문 5개
