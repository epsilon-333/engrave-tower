# 각인의 탑

**탑을 오르며 각인을 새기고, 매번 다른 조합으로 꼭대기를 노리는 2D 도트 액션 로그라이트 RPG.**
섬(아르케의 바람결의 섬)은 준비 · 성장 · 이야기의 무대입니다. 핵심은 **"강한 각인보다 맞물리는 조합이 이긴다"**.

## 한눈에 보는 고리
1. **준비** — 섬에서 레벨(도감) · 장비 · 스킬 · 종족 성지의 축복을 갖춘다.
2. **등반** — 각인의 탑에서 층마다 싸우고 → 보상(각인 · 연마 · 축복 · 금화 · 샘 · 별빛)을 고르고 → 다음 문을 고른다. 5층마다 수호자, 10층마다 구역의 주인.
3. **귀환** — 쓰러져도 **별빛**은 남는다. 별빛으로 **탑의 축복**(영구 성장)을 배운다.
4. **목표** — 50층의 각인의 왕. 그 뒤엔 **서약**(난이도)을 걸고 기록에 도전.
- 무엇을 할지 모르면 **여정**(왼쪽 위 · J)이 다음 한 걸음과 방향 화살표를 보여 준다.

자세한 설계: `docs/탑-등반-개편.md`

## 배포
[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/epsilon-333/engrave-tower)

`render.yaml`에 무료 웹 서비스 설정이 들어 있습니다. Render에서는 진행 상황이 브라우저에 저장됩니다(계정 서버 저장은 claude.ai 공유 페이지 버전에서만 동작).

## 실행
```
node engrave-tower/server.js
```
브라우저에서 http://localhost:5180 에 접속합니다.

조작: WASD 이동 · 마우스 조준 · 좌클릭(누르고 있기) 평타 · 우클릭 무기 기술 · Q·E·R·F 스킬(대검술사는 길게 눌러 차지) · Space 대시 · G 상호작용 · C 캐릭터 · Esc 일시정지

모바일: 왼쪽 조이스틱 이동 · 오른쪽 조이스틱 공격(밀면 그 방향, 누르기만 하면 가까운 적 자동 조준) · Q/대시/확인/R/메뉴 버튼. 세로·가로 모두 지원

## 탑 등반 (본편)
| 구역 | 층 | 5층 수호자 | 10층 주인 | 권장 Lv |
|---|---|---|---|---|
| 이끼 굴 | 1~10 | 가면 족장 | 이끼 군주 | 1+ |
| 독늪 | 11~20 | 늪 마녀 수장 | 늪의 거인 | 8+ |
| 화산 균열 | 21~30 | 방패 악귀 대장 | 균열 수호자 | 16+ |
| 서리 회랑 | 31~40 | 얼음 오우거 왕 | 서리 마녀 | 24+ |
| 그림자 묘지 | 41~50 | 망령 기사단장 | 각인의 왕 | 32+ |

- 층: 적이 물결 셋으로 몰려온다 → 모두 쓰러뜨리면 가운데에 보상 → 문 2개(축복으로 3개) 중 하나로.
- 문의 보상: 각인 · 연마 · 축복 · 금화 · 샘 · 별빛 · 시련(강화된 적, 희귀 이상 각인) · 상인 · 제단(위험과 보상) · 쉼터(수호자 앞).
- 등반에서 새긴 각인은 부하를 차지하지 않고 등반이 끝나면 사라진다. 이미 가진 태그의 각인이 더 잘 나온다.
- 권장 레벨보다 낮으면 레벨 하나마다 적 공격력 +4%(최대 +60%) · 체력 +3%(최대 +45%).
- 탑 안에서는 누구나 최대 체력 +250 (탑의 가호).
- 파티 등반: 파티장이 시작하면 동료도 같은 층에 선다. 보상은 각자, 문은 파티장이 고른다.

## 종족
| 종족 | 고유 메커니즘 |
|---|---|
| 기사 | 오러 게이지가 차면 R로 발동, 5초간 물리 저항 50% 무시 |
| 마법사 | 마나 +50%·회복 +30%, 원소 반응 +50%, 스킬 쿨 -25% |
| 엘프 | 멀리서 맞힐수록 투사체 피해 증가, 사격 중 감속 절반 |
| 오크 | 분노 게이지가 차면 광폭화(공속·흡혈) |
| 수인 | 연타 가속, 대시 2회 충전 |
| 언데드 | 독·출혈 면역, 처치 시 생명력·마나 흡수 |

## 무기와 스킬
무기 23종, 무기마다 Q 스킬(회전베기·충전 일격·돌진 찌르기·회오리·일제 사격·화살비·도끼 폭풍·마력 폭발·서리 고리·역병 웅덩이·유성). 마법 무기는 마나를 소모하고, 민첩 무기(활·단검·쌍검·카타나)는 민첩으로 피해가 오릅니다.

## 조합 시스템
| 층 | 내용 |
|---|---|
| 스탯 8종 | 근력(물공) · 마력(마공) · 민첩 · 체력 · 감각 · 정신(상태이상 저항/감소) · 물리 저항 · 마법 저항 |
| 특수 스탯 | 흡혈 · 반사 · 독성 · 화염/냉기 친화 · 관통 · 강인함 (각인·장비에만 붙음) |
| 특화 보상 | 포인트 효율 구간 ×1.0/1.3/1.7/2.2, 30/50/70/90 각성, **극한**(1위 스탯이 2위의 2배 이상이면 +20%) |
| 조건 효과 | 스탯 임계, 스탯 비교(마력 > 근력), 스탯 차이(물저·마저 차이 10 이하), 태그 수, 종족, 극한, 만능 |
| 태그 시너지 | 화염, 냉기, 독, 출혈, 흡혈, 바람, 거체, 반사, 점액, 그림자, 저주, 불사, 투사 |
| 원소 반응 | 증기 폭발(화상+냉기) · 유독 연기(중독+화상) · 혈빙(출혈+냉기) · 패혈(중독+출혈) |
| 트레이드오프 | 각인 부하 > 한도 → 과부하, 화염·냉기 4개씩 → 상쇄, 묘지기의 계약(피해 +40%, 회복 불가) |
| 저항 상성 | 해골은 물리 저항이 높고, 망령은 물리가 거의 통하지 않음. 지속 피해는 저항을 무시 |

고등급 각인은 부하가 크고 태그가 1개뿐이라, 저등급 각인 여러 개로 시너지를 쌓은 빌드가 더 강해질 수 있습니다.
숨겨진 잔향도 있습니다. 예를 들어 얼음 골렘을 **불타는 상태로** 처치하면 다른 잔향이 나옵니다.

## 코드 구조 (온라인 확장 대비)
```
public/js/
  data/     종족·스탯·각인·몬스터·장비 (순수 데이터, 서버와 공유)
  sim/      build.js 빌드 계산 · conditions.js 조건 엔진 · mapgen.js 필드 생성 · world.js 전투·탐험 (DOM 없음)
  render/   16px 도트 스프라이트 · tiles.js 맵 미리 그리기 · renderer.js 조명·안개·HUD (읽기 전용)
  ui/       마을 화면
  save.js   저장 (순수 JSON)
```
- 전투는 **고정 60틱 + 시드 난수 + 입력**만으로 진행됩니다. 서버에서 같은 코드를 돌리면 서버 권한 방식이나 리플레이 검증이 가능합니다.
- 빌드 코드(캐릭터 탭)로 빌드를 공유합니다. 나중에 고스트 PvP와 랭킹에 사용합니다.

## 근접과 원거리
- 근접 무기: 받는 피해 -20%, 공격을 맞히면 적의 공격 준비를 끊음(경직)
- 원거리 무기: 쏘는 동안 이동 속도 -35%, 40px 안쪽은 피해 -30%, 70px 밖은 +10%

## 전투 조작
- 좌클릭: 기본 공격 (근접 무기는 좌우로 번갈아 베기, 4번째는 강타)
- Q / 우클릭: 무기 스킬. 각인의 적중 효과가 그대로 발동
- R: 오러 개방 (기사)
- Space: 대시 (짧은 무적). 빨갛게 번쩍이는 적은 곧 공격하니 피하기

## 광장 시설
공명 제단(각인 64종, 스타일 필터·배지·목표 찜) · 대장간(장비, 장착 전 수치 변화 미리보기) · 의뢰 게시판(3개 의뢰, 완료 보상) · 서고(도감) · 수련장(교관 스탯 배분, 허수아비 DPS 측정) · 북쪽 관문 5개
